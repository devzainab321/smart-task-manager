 # React Todo App

A simple and responsive Todo App built using React.

## Features
Add New Task
Mark Task as Complete
Delete Task
Show Total Task Count
Responsive Design for Desktop and Mobile
Edit Existing Tasks
Set Task Priority (High, Medium, Low)
Set Task Date and Time
Task Reminder Notifications with Alarm Sound
Search Tasks
Filter Tasks (All, Pending, Completed)
Dashboard with Task Statistics
Clear All Tasks
Save Tasks Using Local Storage
Task Categories
Task Progress Bar
Sort Tasks by Priority and Date
Subtasks / Checklist
Recurring Tasks
Calendar View

## Technologies Used

- React
- CSS
- JavaScript
- Vite
